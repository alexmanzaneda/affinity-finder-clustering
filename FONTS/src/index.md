# Source Code (`src`)

## Summary
The `src` folder contains all the source code and test files for the project, organized following a standard Java project structure.

## Structure

### 📂 `main/java`
Contains the main application code, including:
- **Domain Layer** - Core business logic and domain classes
- **Controllers** - Application controllers that manage the flow
- **Persistence Layer** - Data access and storage management
- **Presentation Layer** - User interface components
- **Exceptions** - Custom exception classes
